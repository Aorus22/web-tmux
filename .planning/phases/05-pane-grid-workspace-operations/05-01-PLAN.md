## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App → Go Backend WS (typed commands) | Pane/window mutations ride correlated `send_command`; untrusted pane titles/paths cross back via snapshots |
| Snapshot geometry → layout math | Untrusted cell dims flow into pixel mapping and view construction |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Tampering | `pane.rename` title input | medium | mitigate | Title travels as JSON `title` field into `select-pane -t %N -T <title>` argv (no shell); trim + non-empty gate client-side; typed dispatch only — server `default:` rejects anything else |
| T-05-02 | Denial of service | `pane_geometry` dims | medium | mitigate | `ww<=0\|\|wh<=0 → zero rect` guard + `i64` internals + `cols.max(2)/rows.max(1)` clamps; zero-dim windows render empty without panic |
| T-05-03 | Denial of service | Split/zoom send path | low | mitigate | Correlated sends with 10s timeout + `is_submitting` guard; no optimistic flips; snapshot truth self-heals |
| T-05-SC | Tampering | Cargo dependencies | high | mitigate | Zero new packages; all imports resolve to milestone-pinned workspace (`gpui-pre =0.3.3`, `gpui-component =0.6.0`) with committed `Cargo.lock` |
</threat_model>
