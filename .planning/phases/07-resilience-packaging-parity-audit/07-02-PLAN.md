## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Dist bundle dir → packaged app launch | A swapped `tmux-gui-server` beside the exe would be executed (binary planting) |
| Makefile → developer shell | Recipes execute with the developer's privileges |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-04 | Tampering | Dist bundle (`tmux-gui-server` sibling) | medium | mitigate | `bundle.rs` `settings.backend_path` override lets users pin an absolute backend path; README notes the expected sibling filenames; no auto-update/download channel added |
| T-07-05 | Tampering | Makefile recipes | low | mitigate | Recipes are one-line delegations to in-repo scripts only (no curl-pipe-shell, no network fetch); scripts build first-party code with pinned lockfile |
| T-07-SC | Tampering | npm/pip/cargo installs | high | mitigate | Zero new packages — scripts invoke only `go`/`cargo`/`rustc`; task asserts empty `git diff` on Cargo.toml/Cargo.lock |
</threat_model>
