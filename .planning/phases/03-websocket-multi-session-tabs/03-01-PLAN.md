<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App -> Go Backend WS (`/api/ws?session=`) | Local WS loopback IPC; untrusted snapshot/delta/command frames cross here |
| Async pump -> GPUI thread | Tagged (session, generation) events cross thread boundary into tab state |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering / DoS | `ws.rs` read pump (serde) | high | mitigate | `serde_json::from_str` drop-and-continue on malformed frames (FE `websocket.ts:106-111` parity); never `unwrap` in the read loop; DTOs use serde `default` discipline so missing fields degrade, never panic |
| T-03-02 | Tampering | `AppState::apply_event` (cross-session leak) | high | mitigate | Triple generation guard: generation equality + envelope session match + tab-liveness entry check before any snapshot commit (STATE-04) |
| T-03-03 | Tampering | `ws.rs` send path (stale-socket write) | medium | mitigate | `send_command` verifies entry generation matches the handle's captured generation before enqueueing |
| T-03-04 | Spoofing | `normalize_ws_url` (session-name injection) | medium | mitigate | Session names percent-encoded as a query value (names may contain `/` per ValidateSessionName); client-side `validate_session_name` pre-flight on any flow that opens a socket by name |
| T-03-SC | Tampering | Cargo dependencies | high | mitigate | Zero new packages — pinned tokio-tungstenite 0.26.2 / futures-util / flume / rand from the committed lockfile only |
</threat_model>
