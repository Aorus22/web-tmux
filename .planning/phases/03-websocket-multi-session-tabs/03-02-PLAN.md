## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> rename dialog | User-supplied new session name crosses into a tmux mutation |
| App -> Go Backend WS (mutations) | Correlated session.rename/session.kill/window.select frames |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-05 | Tampering / Command Injection | `rename_session_dialog` (new name) | medium | mitigate | Client-side `validate_session_name` pre-flight (same Go rules as create) before any send; server re-validates (`service.go:94-97`); inline error on `command.error`, dialog stays open |
| T-03-06 | Tampering (wrong-target mutation) | rename transport selection | high | mitigate | Rename always resolves the TARGET session's own socket (D5); `send_command` generation check prevents stale-handle writes; 03-01 re-resolution test locks the migration |
| T-03-07 | Denial of Service | rename/kill double-submit | medium | mitigate | `is_submitting` short-circuit (DLG1 pattern) disables the confirm button while a correlated command is in flight; 10s forget-timeout releases the flag so it never sticks |
| T-03-08 | Information Disclosure | placeholder Settings page | low | accept | Placeholder renders static copy only — no settings values, paths, or tokens displayed |
| T-03-SC | Tampering | Cargo dependencies | high | mitigate | Zero new packages — gpui-component menu/Dialog/Input already pinned at 0.6.0 in the committed lockfile |
</threat_model>
