## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mouse/wheel → terminal.input | Untrusted pixel deltas converted to control sequences |
| Clipboard → terminal.input | Hostile clipboard bytes forwarded to tmux |
| Window system → terminal.resize | Untrusted container sizes reported to the shared tmux viewport |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05 | DoS | `app_state` resize sender | high | mitigate | Arm-only paint callback + 100ms generation-tagged debounce + cols.max(2)/rows.max(1) clamp; zero-size measures never arm — a drag storm emits one resize per settle and can never shrink the shared viewport |
| T-04-06 | Tampering | `terminal_view` wheel path | medium | mitigate | Notch accumulator with burst clamp 3 bounds PageUp/PageDown repeats per batch; SGR emitted only when TermMode advertises mouse reporting |
| T-04-07 | Injection | `paste_clipboard` | low | accept | Clipboard content passes through to tmux uninterpreted (Electron parity); bracketed-paste negotiated inside tmux, not by the client; no client-side chunking or escaping that could mangle bytes |
| T-04-08 | Spoofing | mock-server interop fixtures | low | mitigate | Fixtures are recorded shapes, served only by in-process test servers; no fixture path reaches production sends |
| T-04-SC | Tampering | Cargo dependencies | high | mitigate | Zero new packages — interop reuses the Phase-3 TcpListener + accept_async shape with no new crates |
