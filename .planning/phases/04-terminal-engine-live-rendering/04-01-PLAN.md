<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Go Backend WS → AppState commit path | Untrusted terminal bytes (capture blobs, output frames) cross here |
| Keyboard/clipboard → terminal.input | User-controlled bytes forwarded to tmux |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-01 | Tampering / DoS | `app_state` terminal commit arms | high | mitigate | Malformed terminal frames drop-and-continue (read-pump serde discipline + no unwrap in commit path); apply_capture fuzzed via unicode/CRLF fixtures so hostile blobs cannot panic the pump |
| T-04-02 | Tampering | `capture.rs` replay path | medium | mitigate | Stale reconnect captures die on the triple-guard generation check; snapshotWritten gate stops re-requested captures doubling the grid |
| T-04-03 | Injection | `terminal.input` paste path | low | accept | Pasted bytes (incl. OSC sequences, huge blobs) pass through to tmux exactly like Electron paste-as-input; the app never interprets them so there is no app-side injection surface; server batcher chunks large writes |
| T-04-04 | DoS | `capture.rs` string splitting | medium | mitigate | Char-boundary-only splitting (str::lines); byte-slicing banned by plan prohibition and locked by the unicode fixture test |
| T-04-SC | Tampering | Cargo dependencies | high | mitigate | Zero new packages — alacritty_terminal 0.25.1 legitimacy-gated in Phase 1 and lockfile re-confirmed in 04-RESEARCH; ported modules are local-file copies, not registry fetches |
</threat_model>
